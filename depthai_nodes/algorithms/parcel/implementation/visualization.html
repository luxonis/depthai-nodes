01 / Input contract

Three views. One metric scene.

The frozen settings expect native images and their calibration, not an RGB-aligned image mask. Each camera can have its own pixel grid.

Geometry

XYZ point cloud

float32[N, 3], finite points in scene millimeters, with an explicit frame ID. Points need not form an image grid.

Keep original row order. Inputs are read-only; segments reference original XYZ indices.

Reference

Supplied support plane

normal · XYZ + offset_mm = 0. The normal is unit length, points upward, and shares the cloud’s frame.

Plane estimation is upstream. This candidate has no plane-estimation callback.

Appearance + calibration

Evaluated native profile: lens-distorted, unrectified source views. Saved color is NV12, decoded to RGB. These sizes occur throughout both recorded splits.

Every view carries its own calibration: intrinsics for the delivered grid, lens-distortion model and coefficients, and a scene-to-camera transform in millimeters. The projector maps XYZ back into the original distorted image. Use actual device calibration, not copied test-camera values.

Resolution is consequential. Visibility uses fixed pixel distances. Resizing images and scaling intrinsics alone does not preserve those tests. The first parcel-node promotion requires the evaluated profile; other grids need separate verification.

02 / Algorithm walkthrough

One scene call. Then one fit per parcel.

Step through the actual stages and frozen thresholds. The drawings are schematic—not a replay or prediction from an evaluated snapshot.

Illustrative geometry · not benchmark data

What makes it “fast”

Same geometric rules as its predecessor, reorganized around shared projections and native reductions. parallel_validation = true is frozen on. All workers finish before the scene call returns or raises; caches reset for each call.

find_candidates(scene)
  project cameras once in parallel
  filter + voxelize + cluster
  prepare shared visibility depth grids
  validate candidates in parallel → CandidateResult[]

for each eligible candidate:
  gather its original XYZ rows → measure(parcel, plane)

What was actually scored

Read this as evidence on these scenes

18 validation snapshots and 17 test snapshots are a small, within-collected-distribution evaluation. These results do not establish performance for other camera modes, scenes, materials, occlusion patterns, or deployment hardware.
